
# Sales Analysis

This Java program finds the consecutive months with the largest total sales change.

The program uses two arrays: one for the months and one for the sales changes in millions of dollars.

It uses nested loops to check different periods and finds the starting month, ending month, and largest total sales change.

## How to Run

Compile:
`javac src/SalesAnalysis.java`

Run:
`java -cp src SalesAnalysis`

## Result

Start Month: Jan

End Month: Oct

Total Sales Change: 62.0 million

## Limitations

The sales data is entered directly in the program. The program does not ask the user to enter new data.
